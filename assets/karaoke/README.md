# Nhạc karaoke local

Đặt file MP3/OGG/WAV/MP4 được phép sử dụng vào thư mục này. Tên file dùng chữ không dấu, số, dấu gạch ngang hoặc gạch dưới.

Khách ở khu karaoke chat `hát Tên bài`. Trong controller, bấm **Kết thúc / mời lượt tiếp**, nhập đường dẫn như `/assets/karaoke/ten-bai.mp3`, rồi bấm **Phát nhạc bài đang chọn**. Âm thanh phát trong overlay; bật âm thanh nguồn Link của Studio. Hết bài, chủ quán chuyển lượt tiếp. Chưa có tìm kiếm nhạc trực tuyến, chấm điểm hay tổng hợp giọng hát.
